# Weather

Weather moves in fronts of about 2½ real minutes, blending from one to the next. Everyone in a
world sees the same weather.

| Weather | How often | What it does |
|---|---|---|
| Clear | most common | fair fishing; salt pans dry fastest |
| Overcast | common | |
| Rain | fairly common | fills livestock troughs with water |
| Fog bank | occasional | fog-only fish surface; you can't see as far |
| Storm | rare | heavy swell and lightning; storm-only fish; rough water for boats |

The [fish table](generated/fish.md) shows which fish bite in which weather.
