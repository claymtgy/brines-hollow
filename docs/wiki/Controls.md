# Controls

You can rebind everything in **Esc → Settings → Controls**. On-screen prompts follow whichever
device you used last.

| Action | Keyboard & mouse | Xbox pad | DualSense |
|---|---|---|---|
| Move / look | WASD / mouse | left stick / right stick | left stick / right stick |
| Jump (swim up) | Space | A | ✕ |
| Sprint | Shift (hold) | LS (hold) | L3 (hold) |
| Sneak | Ctrl (hold) | RS (hold) | R3 (hold) |
| Dodge roll | C | B | ○ |
| Use tool / attack / cast | LMB | RT | R2 |
| Alt use (place, eat, guard) | RMB | LT | L2 |
| Interact: talk, open, board, step off (hold to pick an object up) | F | X | □ |
| Hotbar slot | 1-8 | LB / RB | L1 / R1 |
| Previous / next material or blueprint | Q / E | D-pad left / right | D-pad left / right |
| Brush size | Z / X | D-pad down / up | D-pad down / up |
| Rotate blueprint | R | Y | △ |
| Toggle grid snap | G | View | Touchpad / Select |
| Pick the block you're looking at | MMB | Share | Create |
| Inventory & hand crafting | I / Tab | | |
| Quest log | J / L | | |
| Build menu (with the hammer) | B | | |
| Fast-forward time (solo / host) | hold T | | |
| Swap camera shoulder / first person | V / F5 or P | | |
| Pause menu | Esc | Menu | Options |

Steam Deck and pads with back paddles: the paddles also dodge and sneak.

**In a boat:** W/S row, A/D turn, Shift pulls hard, F steps off (onto land if it's close,
otherwise over the side into the water).
